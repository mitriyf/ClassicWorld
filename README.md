# 📜 ClassicWorld
## 🎻 Go back to the Classic version of Minecraft!
- $ Versions 1.19.4-1.21+ are supported
- $ The world was tested on version: 1.19.4
- $ Note:
  - The world was moved from c0.30-c-1900.
  - There are some changes in the world. They shouldn’t disappoint you!
  - Thank you for reading this. Good luck!
- $ Recommendations:
  - You can install some resource packs below to enhance the gameplay:
    - https://modrinth.com/resourcepack/alexa-classic-craft
    - https://modrinth.com/resourcepack/no-worldborder
    - Attention! If you encounter any limitations, you can download these resource packs from the downloads folder in this repository: https://github.com/mitriyf/ClassicWorld/tree/main/downloads
  - To set the world, use one of the methods below:
    - Single world: just load it into saves. The name can be changed to start.
    - Server method one: Place the folder on the server, and then upload the world using any convenient plugin, following their instructions: MultiWorld, Multiverse-Core, or others.
    - Server method two: rename the downloaded world to world or the one specified in server.properties. If such a world already exists, make a backup, and then delete the unnecessary world -> perform the previous action. Ready!
- $ You can ask other questions in the resource discussion.
